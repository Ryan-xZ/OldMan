# 老头乐 (OldMan)

> 一款面向日常使用的 Android 效率工具集，免费、无广告、注重隐私。
> 本仓库为发布仓库，提供 APK 下载与使用说明。

## ✨ 功能一览

| 模块 | 说明 |
| --- | --- |
| **自动工具** | 基于无障碍的悬浮辅助窗，支持「跳广告」自动点击、调试悬浮窗等能力 |
| **跳广告** | 内置通用规则引擎，接入自动工具；支持关键词 / view-id / 文本查找 / 弹窗关闭与手势兜底，规则可剪贴板导入导出 |
| **排班助手** | 把排班表一键写入系统日历，支持月份快切、实时识别天数、按月删除 |
| **B站助手** | 登录后可查看每日经验任务进度、投币/观看/分享完成情况与升级预估 |
| **应用内更新** | 通过 GitHub Releases 检查新版本，支持国内镜像加速下载并一键安装 |

界面为适老化的大字号、简洁卡片设计，核心操作尽量一步直达。

## 📥 安装

1. 打开本仓库的 [Releases](../../releases) 页面；
2. 下载最新版本的 `OldMan-vX.Y.Z.apk`；
3. 安装前请在系统提示中允许「安装未知来源应用」（仅本应用需要，用于应用内自动更新）。

> 若 GitHub 直连下载缓慢，App 内的更新弹窗提供「镜像站加速下载」入口。

## 🔧 权限说明

| 权限 | 用途 |
| --- | --- |
| 悬浮窗显示 | 展示自动工具悬浮辅助窗 |
| 无障碍服务 | 跳广告等自动化点击（需在系统设置手动开启） |
| 通知 | 悬浮窗前台服务常驻通知 |
| 日历读写 | 排班写入 / 删除系统日历 |
| 网络 | B站数据拉取、更新检查与下载 |
| 安装未知应用 | 应用内更新安装新版 APK |

所有数据均保存在设备本地，B站登录凭证仅存于本机，不上传到任何第三方。

## 🔄 应用内更新

应用启动或「设置 → 检查更新」时，会通过 GitHub Releases 获取最新版本：
- 发现新版本弹出更新说明，可直接「下载安装」或「镜像加速下载」；
- 支持「忽略本次 / 稍后」；关闭后不再重复提醒该版本。
